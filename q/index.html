How It Works

From install to live in minutes

One Windows installer. Connect your API keys, tune your risk policy, paper-trade, then go live. The dashboard walks you through every step.

Run the Windows installer, then paste your Kalshi API key and your OpenRouter key (only needed for AI strategies). Saved securely, no config files.
